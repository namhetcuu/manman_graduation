# Thiệp mời lễ tốt nghiệp — Đàm Phương Nam

Website thiệp mời tương tác, chạy hoàn toàn bằng HTML/CSS/JavaScript.

## Chạy
Cách đơn giản:
1. Mở `index.html` bằng trình duyệt.
2. Nhập tên, ví dụ `Thanh`.
3. Bấm **Mở thiệp**.

Hoặc dùng VS Code + Live Server.

## Gửi link cá nhân hóa
Website hỗ trợ tên qua URL:

`index.html?name=Thanh`

Khi mở link, website sẽ tự điền tên Thanh và tự mở thiệp.

Ví dụ khi deploy lên GitHub Pages/Netlify/Vercel:
`https://ten-cua-ban.github.io/graduation-invitation/?name=Thanh`
